# KeyError: The Keeper of the Golden Key

## Purpose

I developed and submitted this text-based maze game in my first year of university for the
Fundamentals of Programming module, using procedural Python with no third-party dependencies.

## Aim Of the Game

In the game, the player wakes up in an abandoned hospital with the primary objective of escaping.
Players search rooms and collect items to facilitate their escape. Completion times are recorded on a
persistent leaderboard, enabling competition for the fastest escape time.

## How to play

Each menu displays a number preceding each option. Players enter their choices by typing
the corresponding number into the terminal.

## Requirements

KeyError requires Python 3.14 or higher to be installed,
available at [python.org/downloads](https://www.python.org/downloads/)
